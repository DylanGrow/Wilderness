## 🛠️ Features
✅ **Offline-First** – Works without internet (PWA)
✅ **Dark/Light Mode** – Auto-adjusts to system preferences
✅ **Interactive Tools** – Compass, Morse code, solar calculator, cloud/signal guides
✅ **Checklist System** – Packing list with progress tracking
✅ **Print-Friendly** – Optimized for physical copies
✅ **Accessibility** – Keyboard navigation, reduced motion support

## 🚀 Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6+)
- **PWA:** Service Worker, Web App Manifest
- **Responsive:** Mobile-first design (works on all devices)
- **Performance:** Optimized for speed and offline use
